# E-Commerce Sales & Profitability Analytics

## 📊 Project Overview
This project analyzes e-commerce sales and profitability using **Microsoft Power BI** and the **Sample Superstore dataset**. The interactive dashboard provides insights into sales performance, profit trends, customer segments, regional performance, and product categories to support data-driven business decisions.

## 🎯 Project Objectives
- Analyze total sales, total profit, transaction count, and profit margin.
- Identify the best-performing product categories and sub-categories.
- Compare sales and profitability across regions and states.
- Understand sales contribution by customer segment and shipping mode.
- Identify profitable and loss-making transactions.
- Enable interactive analysis using slicers and filters.

## 🛠️ Tools & Technologies
- **Microsoft Power BI** – Dashboard development and visualization
- **DAX** – Measures and calculated columns
- **Microsoft Excel / CSV** – Dataset preparation and data handling
- **Data Visualization & Business Intelligence** – Performance analysis

## 📌 Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Transactions
- Profit Margin

## 📈 Dashboard Features
- Sales by Category
- Regional Sales & Profit Analysis
- Profit Status Distribution
- Sales Contribution by Customer Segment
- Sales Contribution by Shipping Mode
- Top 10 States by Sales
- Sales and Profit by Product Sub-Category
- Interactive slicers for Region, Category, Segment, Ship Mode, and City

## 🔍 Key Insights
The dashboard helps users explore:
- Which product categories and sub-categories contribute most to sales and profit.
- How sales and profit vary across geographic regions and states.
- Which customer segments and shipping modes contribute to revenue.
- Where losses occur and which areas may require business attention.

*Actual findings should be added after validating the results in the Power BI dashboard.*

## 🚀 How to Use
1. Download or clone this repository.
2. Open the Power BI `.pbix` file using Microsoft Power BI Desktop.
3. Refresh the dataset if required.
4. Use the dashboard slicers to explore sales and profitability.
